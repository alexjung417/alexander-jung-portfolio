# Alexander Jung — Data Analytics Portfolio

## Included files
- `index.html` — webpage structure
- `css/styles.css` — colors, layout, and responsive styling
- `js/config.js` — your name, links, bio, skills, project, and Tableau dashboard details
- `js/main.js` — loads your config into the page
- `assets/favicon.svg` — browser tab icon

## Open in VS Code
1. Download and unzip this project.
2. Open VS Code → **File → Open Folder...** → select this folder.
3. Install the **Live Server** extension (Ritwick Dey).
4. Right-click `index.html` → **Open with Live Server**.

## Personalize it
Edit `js/config.js`. Replace the placeholder email, add your LinkedIn URL if desired, and review the bio/skills. Only the selected team capstone and two supplied Tableau dashboards are featured; the site does not automatically list all GitHub repositories.

## Publish with GitHub Pages
1. Create a new GitHub repository for your portfolio.
2. Upload the contents of this folder to the repository root (`index.html` must be at the root).
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will display the published website URL on the Pages screen.

Before publishing, confirm your bio and skills, replace the placeholder email, and test the Tableau embeds on desktop and mobile. If an embed does not show, use its direct Tableau Public link.
